## 3. Recording Progress

For every completed stage, record:

- Date completed
- Files created, moved or modified
- Functionality affected
- Tests performed
- Test results
- Outstanding issues

## 4. Completion Rules

A stage is complete only when:

1. Its planned changes are implemented.
2. Related functionality has been tested.
3. Existing functionality remains operational.
4. Documentation is updated.
5. Outstanding issues are recorded.
