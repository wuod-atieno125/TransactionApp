

# PATUMAS Architecture Decisions

## 1. Purpose

Record important decisions that guide PATUMAS development.

## 2. Approved Decisions

| ID | Decision | Status |
|---|---|---|
| ADR-001 | Retain React 19, Vite, Node.js, Express 5 and PostgreSQL | Approved |
| ADR-002 | Use a Hybrid Feature-Based Modular Architecture | Approved |
| ADR-003 | Restructure the existing application incrementally | Approved |
| ADR-004 | Keep one PostgreSQL database | Approved |
| ADR-005 | Give each module clear responsibility | Approved |
| ADR-006 | Keep shared functionality in shared directories | Approved |
| ADR-007 | Enforce permissions on the backend | Approved |
| ADR-008 | Preserve existing functionality during restructuring | Approved |
| ADR-009 | Document and test every migration stage | Approved |

## 3. Future Module Decisions

The planned future modules are:

- Welfare Management
- Shares Management
- Emergency Contributions

Their implementation will follow the modular architecture.

## 4. Document Control Note

The original SRS is Version 0.4 (Draft). The original SDD is Version 1.1 (Draft for Review).

The modular architecture and migration approach have been approved by the project owner. This does not automatically make the original SRS and SDD formally approved.

## 5. Changing a Decision

A change to an approved architectural decision must be discussed, approved and recorded here before implementation.
